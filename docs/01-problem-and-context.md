# 01 現況與需求

整理自 2026-09 的需求訪談。標 **[假設]** 的是尚未確認、目前先這樣認定的項目。

## 業務型態

- 代工(OEM):規格由客戶給,不同客戶、不同料號的允收標準不同
- 產量不固定,依工件大小而異;各製程工時不同

## 零件

- 圓形閥門零件,直徑 **3 吋 ~ 14 吋**(約 76mm ~ 356mm)
- 鑄件,加工後檢驗
- 有治具(定位不是問題)
- 鑄件來源:**[假設]** 外購

## 缺陷與痛點

| 缺陷 | 說明 | 目前怎麼檢 |
|---|---|---|
| 鏽蝕 | 表面鏽斑 | 目檢 |
| 鑄孔(砂孔/氣孔) | 加工後露出的小凹坑 | 放大鏡目檢 |

- 缺陷尺寸沒有固定門檻,平常要用放大鏡檢驗 → 屬 **0.1~0.5mm 級**
- **每一批來的問題點不一樣** → 事先無法窮舉缺陷樣態
- 異常件流到下游會造成機械損壞,成本高
- 要求 **全面檢測**(所有面)
- 現有防範與防呆機制擋得住尺寸/組裝類問題,擋不住「要看才知道」的外觀缺陷 **[假設,待確認原意]**

## 對方案的關鍵含意

1. 14 吋件無法一張照片涵蓋(要看清 0.1mm 需 ~12,000 像素寬)→ 外觀檢測必須分區拍或**線掃 + 旋轉台**
2. 「每批問題不一樣」→ 外觀檢測用**異常偵測**(學正常、抓不像),不用分類
3. 有三次元 → **相機不碰尺寸**,尺寸層是純數據整合
4. 產量不定、節拍不一 → 做**獨立檢驗站**,不做跟輸送帶的線上檢測
5. 代工 → 規格模組本質是「客戶 → 料號 → 允收標準」,並要能一鍵產出客戶檢驗報告
