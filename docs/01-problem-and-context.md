# 01 現況與需求

整理自 2026-09 兩輪需求訪談。標 **[待確認]** 的是尚未回答的項目。

## 業務型態

- 代工(OEM):規格由客戶給,不同客戶、不同料號的允收標準不同
- 產量不固定,依工件大小而異;各製程工時不同
- **產量重心:6 吋 ~ 10 吋**

## 零件與製程

- 圓形閥門零件,直徑 **3 吋 ~ 14 吋**(約 76mm ~ 356mm)
- **毛胚鑄件由上游鑄造廠供應**,回廠加工
- 加工機:**車床 + 銑床共 10 台**,年份不詳,控制器品牌 **[待確認]**
- 有治具(定位不是問題)
- 內孔每個規格不同(內孔檢測要依料號設定)

## 缺陷與痛點

| 缺陷 | 來源 | 責任 | 目前怎麼檢 |
|---|---|---|---|
| 鏽蝕 | 多半廠內產生(停留/濕度/切削液) | 自己 | 目檢 |
| 鑄孔(砂孔/氣孔) | 鑄造帶來,加工後露出 | **退回上游廠商** | 放大鏡目檢 |

- 缺陷尺寸沒有固定門檻,平常要用放大鏡檢驗 → 屬 **0.1~0.5mm 級**
- **每一批來的問題點不一樣** → 事先無法窮舉缺陷樣態
- 異常件流到下游會造成機械損壞,成本高
- **全檢**,每件每面
- **人工目檢速度:約 30 秒/件**(分類一個物件)— 這是很快的基準,AOI 第一版難以超越
- 現有防範與防呆機制擋得住尺寸/組裝類問題,擋不住「要看才知道」的外觀缺陷(已確認)
- 漏放 NG 與誤殺 OK 的損失都可承受,但須避免 → 門檻取平衡,不確定件進人工複判

## 量具

已具備完整工業量測能力,**量測精度不是缺口**:

- 三次元量測儀(CMM)— 首件 / 抽檢 / 全尺寸報告;軟體品牌 **[待確認,看螢幕軟體名稱]**
- 分厘卡、高度規、游標卡尺 — **Mitutoyo 三豐**(U-WAVE 藍牙模組相容)
- **一個料號 12 ~ 17 個尺寸要量** → 手抄量大,數位化價值高

## 資訊系統

- **有 ERP**,品牌 **[待確認]** → 批次身分(採購批號 / 工單號)應從 ERP 取,不另造
- 客戶檢驗報告:**目前無範本** → 由本專案設計

## 預算與期待

- 尚未設定預算,目前階段是**探索 AI 能幫上哪些忙**
- → 路線圖以「最低投入、最快看到價值」排序,第 0 期不買硬體

## 對方案的關鍵含意

1. 產量重心 6~10 吋(152~254mm):254mm 一張 20MP 只到 0.05mm/像素,0.2mm 以下鑄孔抓不穩 → **AOI 第一期就要旋轉台**(分區拍或線掃),不走「小件單相機」
2. 「每批問題不一樣」→ 外觀檢測用**異常偵測**(學正常、抓不像),不用分類
3. 有三次元 → **相機不碰尺寸**,尺寸層是純數據整合
4. 人工 30 秒/件 → **AOI 的價值是一致性 + 每件留證據 + 把人從「看」解放,不是省時間**;要先跟廠內講開
5. 鑄孔退上游 → 檢驗紀錄 = **索賠證據**;且加工工時是自己的成本 → 應評估**進料檢驗**先擋一部分
6. 產量不定、節拍不一 → 做**獨立檢驗站**,不做跟輸送帶的線上檢測
7. 代工 → 規格模組本質是「客戶 → 料號 → 允收標準」,並要能一鍵產出客戶檢驗報告(無範本,自己設計)
