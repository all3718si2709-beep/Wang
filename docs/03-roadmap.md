# 03 分期路線圖

原則:**先數位化,再分析,最後才是視覺 AI。** 順序反過來做的廠,通常是買了相機然後放在角落。

每一期都有「閘門」:沒過閘門不進下一期,避免投資堆在沒驗證的東西上。

## 第 0 期 現在 ~ 3 個月:數位化地基

**做什麼**
- 規格引擎(客戶 / 料號 / 允收標準 / 版本)
- 批次身分(接 ERP 採購批號 / 工單號,D11)
- 三次元報告自動匯入
- 現有紙本 / Excel 檢驗表(12~17 個尺寸)搬進系統
- 手工量具藍牙化,量完自動進系統
- 外觀目檢結果也錄進系統(先人判,系統記)
- 一鍵產出批次檢驗報告 / COC

**投入**:軟體開發 + 幾個藍牙量具模組
**技術風險**:無
**回收**:省抄寫、報告自動、客訴可回溯、**開始累積數據**

**閘門**:現場實際用滿一個月、至少 3 個料號跑過完整流程

## 第 1 期 3 ~ 6 個月:分析 + AOI 離線驗證

**做什麼**
- 鏽蝕原因分析:檢驗紀錄時間戳 + 各站停留時間 + 溫濕度記錄器 → 找出鏽蝕與哪個站 / 哪個季節 / 停留多久相關
- 批次風險預測:批次身分 × 缺陷率,進料時提示高風險批加嚴檢驗
- 尺寸趨勢預警
- **AOI 離線驗證(6~10 吋)**:現有零件 + 留存 NG 件 + 相機 + 固定打光 + 手動旋轉,本機驗證鏽蝕 / 鑄孔可抓到的最小尺寸與誤殺率
- **進料檢驗評估(D10)**:統計「加工後才發現鑄孔退回」佔多少件、每件浪費多少機台工時 → 決定值不值得設進料站

**投入**:溫濕度記錄器(數百元)、一台相機 + 光源(驗證用)
**回收**:鏽蝕率下降(預防比檢出便宜)、檢驗人力聚焦高風險批

**閘門**:AOI 離線驗證報告 — 漏檢率 / 誤殺率 / 可抓最小缺陷,數字拿去對現場放大鏡目檢的水準

## 第 2 期 6 ~ 12 個月:AOI 檢驗站上線(6~10 吋為主)

**做什麼**
- 獨立檢驗站:旋轉台 + 面陣相機分區拍 + 雙光源、治具、操作介面(D6 修訂)
- 判定三態 OK / NG / 待複判(D12)
- 若第 1 期評估划算:毛胚進料檢驗(同站或簡化站)
- AOI 輸出接規格引擎判定
- 量測策略優化(三次元抽檢集中在會飄的尺寸)

**投入**:工業相機、光源、站體、硬體整合商
**回收**:判定一致、每件有照片(客訴 / 退上游證據)、人從「看」轉去做判斷;**不以省時間為目標**(D9)

**閘門**:現場並行運作(AOI + 人檢)一個月,AOI 漏檢不高於人檢;待複判比例低於可負擔量

## 第 3 期 1 年+:AOI 升級與製程端

- 線掃相機升級(若面陣分區拍解析度或節拍不足)、內孔內視鏡、3 吋與 14 吋配方
- CNC 刀具磨耗預測(10 台車銑,先盤點控制器品牌能否取數據)
- 歷史工單工時學習 → 報價與排程估得準
- 老師傅經驗知識庫(這種鑄孔怎麼判、這種鏽怎麼處理)

## 各期硬體與角色分工

| 角色 | 負責 |
|---|---|
| 軟體 / AI | 規格引擎、資料整合、異常偵測模型、報告產出 |
| 硬體整合商 | 檢驗站機構、光學架設、旋轉台、治具 |
| 廠內品管 | 允收標準定義、OK 件樣本、驗證期並行判定 |
