# 04 AI 製程優化地圖

從進料到出貨,逐站看 AI 能幫什麼、不能幫什麼。前提:**AI 沒有數據就是空的**,每一項都依賴第 0 期的資料底座。

## ① 進料(鑄件)— 批次風險預測

「每一批來的問題點不一樣」本身就是 AI 題目。
- 資料:供應商、爐號、材質證明、鑄造日期 × 後續檢驗缺陷率
- 累積幾十批後:進料時提示「這批與上次出鑄孔的同爐,建議加嚴」
- 效果:**風險式抽檢** — 檢驗力氣集中高風險批,低風險批放寬
- 鑄件外購(已確認)→ 這一項就是**供應商評分**:每批鑄孔率、退回率、尺寸穩定度,拿數據跟上游談
- 鑄孔退上游 → 每件檢驗紀錄(照片 + 位置 + 批次)= **索賠證據**
- **進料檢驗(D10)**:加工工時是自己的成本,毛胚進廠先擋表面鏽蝕 / 明顯鑄孔 / 變形,擋掉一成省一成機台時間;多數鑄孔加工後才露出,只能擋一部分
- 三次元的幾何數據可反推鑄件收縮不均 → 給鑄造端的證據

## ② 鏽蝕 — 找原因,不只抓

鑄孔是鑄造帶來的只能擋;**鏽蝕多半是廠內產生的**:加工後到檢驗停多久、切削液殘留、倉儲濕度、季節。
- 資料:檢驗紀錄時間戳 + 各站進出時間 + 溫濕度記錄器
- 產出:「哪個站停留超過 N 天鏽蝕率跳」「哪個月份異常」
- **預防一件比檢出一件便宜得多** — 最被低估的槓桿

## ③ 外觀檢測(AOI)

見 [02 架構 第三層](02-architecture.md)。AI 含量最高、硬體投入最大,排在①②之後。

## ④ 尺寸量測 — 數位化,不 AI 化

見 [02 架構 第二層](02-architecture.md)。AI 只做趨勢預警與量測策略優化。

## ⑤ 加工段 — 刀具壽命與參數(中長期)

- 現況:車銑共 10 台,年份不詳;先盤點控制器品牌(Fanuc / Mitsubishi / Heidenhain / Siemens)與有無網路口,決定能否取主軸負載、加工時間
- 累積後:刀具磨耗預測、換刀時機建議
- 有效但需接機台,一年以上

## ⑥ 排程 — 「產量不定、製程時數不一」

- 真正的解法是**排程演算法**,不是 AI(講清楚)
- AI 的角色:把歷史工單**實際工時**學起來,新單估得準,排程才排得準
- 代工廠估工時不準 = 報價不準 + 交期不準

## ⑦ 報價與文件 — 最快回本、常被忽略

不需要硬體、不需要等數據累積,用現成大語言模型即可:
- 客戶丟圖紙 / RFQ → AI 讀圖、比對歷史類似料號 → 工時與成本估算草稿
- 出貨檢驗報告 / COC 從系統資料自動產出
- 客訴 → 8D 報告草稿從檢驗紀錄與批次紀錄自動拉
- 老師傅經驗整理成可問答的知識庫

## AI 不能做的(避免期待錯位)

- 不能取代三次元 / 卡尺量尺寸
- 不能修好鑄造本身的問題,只能擋與回饋
- 不能在沒有數據的情況下「優化製程」
- 排程本質是最佳化演算法,AI 是輔助估算
