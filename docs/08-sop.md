# 08 檢驗作業 SOP(qc-app 第 0 期)

分三段:**一次性建檔**(品管主管)、**每批檢驗**(檢驗員)、**每月**(品管主管)。

## 一、一次性建檔(每個料號只做一次)

| 步驟 | 頁面 | 做什麼 |
|---|---|---|
| 1 | 設定 | 填公司名稱、地址、電話、報告頁尾聲明(印在報告上) |
| 2 | 客戶 | 新增客戶(代號 + 名稱) |
| 3 | 供應商 | 新增上游鑄造廠(退貨報表依此彙整) |
| 4 | 料號與規格 → 新增料號 | 客戶、料號、品名、圖號 / 版次、材質、吋數 |
| 5 | 料號頁 → 建立第一版 | 進入規格編輯頁 |
| 5a | 尺寸項次 | 照圖面逐項填:特性、圖面位置、標稱、上下公差、量具、頻率、關鍵特性。**頻率**:手工量具填「每件」;三次元填「抽檢」或「首件」 |
| 5b | 外觀矩陣 | 預設全部拒收。依客戶規範逐格放寬:勾「允許」→ 填尺寸上限 mm、數量上限。密封面通常全留拒收 |
| 5c | 判定參數 | 警戒比例預設 0.8(用掉 80% 公差帶標黃) |
| 6 | 生效此版本 | 鎖定。之後要改 → 料號頁「以現行版本開新版」→ 改 → 生效;舊批仍依舊版判定 |

## 二、每批檢驗

| 步驟 | 動作 |
|---|---|
| 7 | **開批**:檢驗批 → 開新檢驗批 → 料號、類別(FQC / IQC / FAI / IPQC)、數量、鼎新工單號、採購批號、供應商、爐號、檢驗員 |
| 8 | **擺件**:件依序排好,件號 #1~#N 對應實體順序;有刻字在件面板填序號 |
| 9 | **量尺寸(逐項模式,預設)**:拿一支量具,點該項次第一格 → 量 #1 → 藍牙傳送或手打 → Enter → 自動跳 #2 … → 量完全部件自動跳下一項次 → 換量具。綠 = 合格、黃 = 接近公差邊緣、紅 = 超差。三次元項目不在此輸入(第二版匯入),勾「顯示抽檢 / 首件項次」可手填 |
| 10 | **看外觀**:每件目視 / 放大鏡看六區域。**有缺陷才記**:點件號 → 區域 → 缺陷類型 → 尺寸 / 數量 / 時鐘方位 → 拍照 → 看引擎預判 → 加入。責任歸屬預設:I~XII 上游、鏽蝕 / 加工損傷廠內,可改 |
| 11 | **處理待複判與 NG**:「待複判」= 規格未定義此組合,必須由人判(填理由 → 判允收 / 拒收)。NG 件選處置:報廢 / 重工 / 退回供應商 / 特採 |
| 12 | **結批**:所有件為允收或拒收後 → 批結論(允收 / 拒收 / 特採)→ 結批鎖定。要補資料先「重開」 |
| 13 | **出報告**:檢驗報告 → 列印 → 另存 PDF |

### 逐項 vs 逐件

- **逐項**(預設):同一支量具量完所有件再換 → 換量具次數最少,現場最快
- **逐件**:一件量完所有項次再換下一件 → 適合件很大、搬動成本高的情況

## 三、每月

| 步驟 | 動作 |
|---|---|
| 14 | 退供應商報表 → 選月份 → 列印 → 附照片與上游談退貨 / 扣款 |
| 15 | 備份:複製 `qc-app/data/` 整個資料夾(資料庫 + 照片) |

## 藍牙量具接法(Mitutoyo)

1. 量具端:U-WAVE-TCB(卡尺)/ U-WAVE-TMB(分厘卡)發射器;接收端:U-WAVE-R 插電腦 USB
2. 用 U-WAVEPAK 把接收器設為 **Keyboard 模式**、資料後加 Enter(設一次)
3. 之後量具按 DATA 鍵 = 電腦打字 + Enter,系統不需任何設定。游標在哪格,值就進哪格
4. 高度規:接 Digimatic 輸出線 → U-WAVE-T 或 USB-ITN 線(同樣鍵盤模式)

## 常見問題

- **打錯值**:回到該格改掉 → Enter 或點別處即覆蓋;清空 = 刪掉內容後 Enter
- **件面板打不開 / 欄位灰掉**:批已結,先在批頁「重開此批」
- **開批時說「尚無生效的允收標準」**:料號規格還是草稿,回料號頁生效
- **報告抬頭是「請至設定填入」**:設定頁填公司名稱
- **待複判太多**:代表外觀矩陣有很多組合沒定義,開新版規格把常見組合定清楚
