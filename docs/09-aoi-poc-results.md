# 09 AOI 離線驗證 — 步驟 A 結果(2026-09-11)

## 做了什麼

在本機(RTX 5060 Laptop)實作異常偵測 pipeline(`aoi/`),用公開金屬圓件缺陷資料集 MVTec AD metal_nut 驗證「只餵 OK 件、抓任何不像正常的東西」是否可行。

## 結果

| 指標 | 值 |
|---|---|
| 訓練資料 | 200 張 OK,0 張 NG |
| 影像級 AUROC | 0.999 |
| 像素級 AUROC | 0.990 |
| 漏檢(門檻只用 OK 件定) | 0 / 93 |
| 誤殺 | 1 / 22(4.5%)→ 進待複判 |
| 推論 | 91 ms / 張 |

## 對本案的含意

1. **方法可行**:符合「每批問題不一樣、無法窮舉 NG」的現實(D2)
2. **硬體門檻低**:筆電 GPU 即可,不需伺服器;推論 < 0.1 秒,節拍瓶頸在拍照與翻面而非 AI
3. **與 qc-app 已接通**:`push_to_qc.py` → `/api/aoi/findings` → 該件外觀發現「AI 偵測異常(待分類)」→ 引擎判待複判 → 人確認(D12)
4. **下一個閘門 = 你們零件的照片**(步驟 B,拍照規範見 [aoi/README.md](https://github.com/all3718si2709-beep/Wang/blob/main/aoi/README.md)),驗三個數字:漏檢、誤殺、可抓最小缺陷 mm
