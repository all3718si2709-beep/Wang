# 07 檢驗表與允收標準(業界標準版)

廠內無既有範本,依業界通用格式設計。這份文件就是**規格引擎的欄位設計圖**。

## 依據的標準

| 標準 | 用在哪 | 備註 |
|---|---|---|
| **MSS SP-55** | 閥門鑄件**外觀**缺陷分類與允收 | 閥門 / 法蘭 / 管件鑄件表面不規則的目視評估標準,業界最常被客戶引用;附照片比對板 |
| ASTM A802 | 鑄件表面允收(目視) | 與 SP-55 互補,客戶有指定時用 |
| ISO 9001 §8.6 | 產品放行需有檢驗紀錄與放行人 | 表單一定要有判定 + 簽核 |
| PPAP 尺寸結果表 / AS9102 Form 3 | **尺寸**檢驗表版面 | 「項次 / 特性 / 規格 / 公差 / 量具 / 量測值 / 判定」的通用版面 |
| ISO 2859-1 (AQL) | 抽樣 | 目前全檢用不到,保留給未來風險式抽檢 |

> ⚠️ MSS SP-55 的缺陷分類與比對板內容需以**正式購買的標準文本**為準,以下分類為規劃用摘要。

## 一、表頭(所有表共用)

| 欄位 | 來源 |
|---|---|
| 客戶 | 規格引擎 |
| 品名 / 料號 / 圖號 / 圖面版次 | 規格引擎 |
| 工單號 / 採購批號 | **鼎新 ERP**(D11) |
| 毛胚供應商 / 爐號 | ERP 採購單或進料單 |
| 批量 / 檢驗數量 | ERP + 現場 |
| 檢驗類別 | IQC 進料 / IPQC 製程 / FQC 最終 / FAI 首件 |
| 檢驗日期、檢驗員 | 系統帶入 |
| 允收標準版本 | 規格引擎(判定可回溯) |

## 二、尺寸檢驗紀錄(IPQC / FQC / FAI 共用版面)

每料號 12~17 項。

| 項次 | 特性(尺寸名稱) | 圖面位置 | 標稱 | 下公差 | 上公差 | 量具 | 頻率 | 件1 | 件2 | … | 判定 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 1 | 外徑 | A | 254.00 | -0.05 | +0.05 | 三次元 | 首件+抽檢 | | | | |
| 2 | 總厚 | B | 38.00 | -0.10 | +0.10 | 分厘卡 | 每件 | | | | |
| … | | | | | | | | | | | |

**欄位規則**
- 量具:三次元 / 分厘卡 / 高度規 / 卡尺 / 塞規 / 其他;決定資料怎麼進來(CSV 匯入 or 藍牙)
- 頻率:每件 / 首件 / 每 N 件 / 首末件 / 三次元抽檢
- 量測值自動比公差 → 判定 OK / NG,超差標紅;接近公差邊緣(例如用掉 80% 公差帶)標黃 → 趨勢預警的原料
- 三次元結果:從 CMM 軟體 CSV 匯入,對應到項次(軟體名稱待確認)

## 三、外觀檢驗紀錄(依 MSS SP-55 分類)

| 代號 | 缺陷類型(SP-55) | 中文 | 本廠常見 | 責任 |
|---|---|---|---|---|
| I | Hot tears, cracks | 熱裂 / 裂紋 | | 上游 |
| II | Shrinkage | 縮孔 | | 上游 |
| III | Sand inclusions | 夾砂 / 砂孔 | ✅ | 上游 |
| IV | Gas porosity | 氣孔 | ✅ | 上游 |
| V | Veining | 脈紋 | | 上游 |
| VI | Rat tails | 鼠尾 | | 上游 |
| VII | Wrinkles, laps, folds | 皺皮 / 摺疊 | | 上游 |
| VIII | Cold shuts | 冷隔 | | 上游 |
| IX | Scabs | 結疤 | | 上游 |
| X | Chaplets | 撐釘痕 | | 上游 |
| XI | Weld repair areas | 補焊區 | | 上游 |
| XII | Surface roughness | 表面粗糙 | | 上游 |
| R | Rust / corrosion(非 SP-55,自訂) | 鏽蝕 | ✅ | **廠內** |
| M | Machining damage(自訂) | 加工刮傷 / 碰傷 | | 廠內 |

**每個料號的允收標準 = 缺陷類型 × 區域 × 允收等級**

| 區域 | 說明 | 預設嚴格度 |
|---|---|---|
| 密封面 | 與閥座/閥板接觸面 | 最嚴,通常任何 III / IV 不允收 |
| 加工面(非密封) | 端面、外圓、內孔加工面 | 依客戶,通常允許小於 X mm、數量 ≤ N |
| 非加工面 | 鑄造原貌 | 依 SP-55 比對板等級 |

紀錄欄位:件號 / 面(端面 A、端面 B、外圓、內孔、密封面)/ 缺陷代號 / 位置(時鐘方位 + 半徑)/ 尺寸估計 mm / 數量 / 照片 / 判定 OK / NG / 待複判(D12)/ 責任歸屬(上游 / 廠內)

> 責任歸屬欄位是為了**退上游**:月底可以直接拉出「本月退回供應商 X 的 III / IV 類缺陷共 N 件,附照片」。

## 四、進料檢驗 IQC(毛胚,D10 評估中)

只看外觀 + 幾個關鍵毛胚尺寸,目的是在加工前擋掉明顯不良:
- 外觀:SP-55 類型 I / II / VII / VIII / IX 明顯可見者、表面鏽蝕、變形
- 尺寸:毛胚外徑、厚度是否夠加工(留料量)
- 判定:允收 / 退回 / 特採(限某製程)

## 五、出貨檢驗報告(給客戶,FQC / COC)

一鍵產出,PDF。內容:
1. 表頭(客戶、料號、圖號版次、工單、批量、出貨數)
2. 尺寸結果摘要:每項次 標稱 / 公差 / 實測 Min–Max / 判定(全檢時附每件明細附錄)
3. 外觀結果:依 SP-55 分類逐項「無 / 允收範圍內」;NG 件數與處置
4. 材質:轉附上游材質證明編號
5. 結論:允收 / 拒收 / 特採
6. 簽核:檢驗 / 審核 / 核准 + 日期
7. 附錄(選):三次元原始報告、每件照片索引

## 六、與規格引擎資料模型的對照

| 表單概念 | 資料表 |
|---|---|
| 表頭 | `inspection_lot`(關聯 ERP 工單 / 採購批) |
| 尺寸項次定義 | `part_dimension_spec`(料號 × 項次,有版本) |
| 外觀允收定義 | `part_visual_spec`(料號 × 缺陷代號 × 區域 → 允收上限,有版本) |
| 每件尺寸量測 | `dimension_measurement` |
| 每件外觀紀錄 | `visual_finding`(含照片路徑、責任歸屬) |
| 判定 | 由引擎依 spec 版本計算,存 `piece_verdict` |
| 報告 | 由以上即時渲染,不另存資料,只存 PDF 快照 |

## 鼎新 ERP 接法(D11)

鼎新有多條產品線(Workflow ERP GP、TIPTOP GP、ERP II、cosmos),資料庫與匯出方式不同,**需確認是哪一條**。第 0 期不管哪一條都先走最保險的路:

1. **第一版**:從鼎新匯出工單 / 採購單 Excel(所有版本都能),系統匯入,對應批次
2. **第二版**:資訊人員給唯讀 DB 帳號(Workflow 多為 MS SQL、TIPTOP 多為 Oracle),排程自動同步
3. 不寫回 ERP,只讀
