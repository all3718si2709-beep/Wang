# 06 決策記錄

已拍板的判斷與理由。要推翻請開 Issue 說明新資訊。

## D1 相機不碰尺寸
- **決定**:尺寸量測維持三次元 + 手工量具,相機只做外觀
- **理由**:三次元已達 0.001~0.005mm,遠高於需求;相機在 356mm 上做到卡尺精度需遠心鏡頭 + 恆溫,成本不合理且風險高
- **日期**:2026-09

## D2 外觀檢測用異常偵測,不用分類
- **決定**:模型學 OK 件,抓不像的
- **理由**:每批問題不一樣,無法事先收齊 NG 樣本;好件長一樣、壞件各異
- **日期**:2026-09

## D3 AI 不直接判 NG
- **決定**:AOI 輸出缺陷清單,規格引擎依允收標準下判定
- **理由**:代工要能對客戶解釋判定依據、可稽核;規則可追溯到版本
- **日期**:2026-09

## D4 獨立檢驗站,不做線上即時
- **決定**:零件放治具 → 拍 → 判 → 下一件
- **理由**:產量不定、各製程節拍不一,跟輸送帶綁死成本高且不必要
- **日期**:2026-09

## D5 先數位化再 AI
- **決定**:第 0 期只做規格引擎、量具整合、批次身分、報告產出;AOI 排第 2 期
- **理由**:AI 需要數據;先驗證再採購;第 0 期零技術風險且立即有回收
- **日期**:2026-09

## D6 小件先、大件後
- **決定**:AOI 先做 3~6 吋(單相機一張涵蓋),14 吋線掃 + 旋轉台留第 3 期
- **理由**:14 吋要 ~12,000 像素寬才能看 0.1mm,單相機做不到;小件先證明方法可行
- **日期**:2026-09

## D7 資料不上雲
- **決定**:照片、量測數據、客戶規格全留廠內
- **理由**:客戶規格與製程資料屬機密;AI 模型在本機訓練與推論可行
- **日期**:2026-09

## D8 先用手機拍照驗證,再買相機
- **決定**:第 1 期 AOI 離線驗證用現有零件 + 一般相機 + 固定打光
- **理由**:花時間不花錢;先知道抓得到多小、誤殺多少,再決定相機規格
- **日期**:2026-09
