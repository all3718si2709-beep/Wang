# 三次元報告範例檔

用來試「匯入三次元」功能,對應示範料號 VD-8-150。

| 檔 | 模擬軟體 | 特色 |
|---|---|---|
| pcdmis_VD-8-150_piece03.csv / piece04.csv | PC-DMIS | 抬頭有 SER NUMBER(自動當件號)、特性 + 軸兩欄、逗號 |
| mcosmos_VD-8-150_multi.csv | Mitutoyo MCOSMOS | 分號分隔、中文特性名、一檔兩件(「工件」欄) |
| calypso_VD-8-150_piece07.txt | Zeiss Calypso | Tab 分隔、英文特性名、實測欄在標稱前面 |

試法:檢驗批 → 開一批 VD-8-150(或用示範批 L-260910-001)→「匯入三次元」→ 選這些檔。
