品質檢驗系統 操作說明

閥門零件 · 規格引擎 + 檢驗紀錄 + 報告 · 資料留在本機

整體流程1 第一次使用2 建料號與規格3 開檢驗批4 量尺寸5 記外觀6 判定與結批7 出報告8 退供應商AI 檢測常見問題

整體流程

建料號 + 規格→開檢驗批→量尺寸→記外觀→判定 / 結批→出報告

左邊選單就是這幾個頁面。料號與規格每個料號只做一次;檢驗批每批做一次。

儀表板:近 30 天概況、進行中的批、缺陷分布。

判定顏色

標籤意思
允收合格
警戒合格,但已經用掉 80% 公差,要注意(可能是刀具磨耗前兆)
拒收不合格
待複判系統不確定(規格沒定義這種情況、或 AI 抓到異常),要由人判
未完成該量的尺寸還沒量完

1第一次使用(只做一次)

誰做:品管主管
  1. 點左邊 設定 → 填公司名稱、地址、電話 → 儲存。這會印在報告抬頭上。
  2. 點 客戶 → 右邊「新增客戶」填代號(例如 C001)和名稱 → 新增。
  3. 點 供應商 → 新增上游鑄造廠(退貨報表會依供應商分)。
客戶頁:左邊清單可直接改,右邊新增。

2建料號與允收標準(每個料號一次)

誰做:品管主管,拿著客戶圖面
  1. 點 料號與規格 → 右上「新增料號」→ 填客戶、料號、品名、圖號版次、材質、吋數 → 建立。
  2. 進到料號頁 → 按「建立第一版」。
  3. 一、尺寸項次:按「新增項次」,照圖面一項一項填:特性名稱、標稱、下公差、上公差、量具、頻率。
    頻率怎麼選:分厘卡 / 高度規 / 卡尺量的填「每件」;三次元量的填「抽檢」或「首件」。
  4. 二、外觀允收矩陣:一開始全部是「拒收」。依客戶規範,把可以接受的格子勾「允許」,填尺寸上限(mm)和數量上限。
    例如「外圓 × IV 氣孔」勾允許、≤0.5、×2 = 外圓上 0.5mm 以下的氣孔最多 2 個可接受。密封面通常全部留拒收。 → 儲存外觀矩陣。
  5. 右上按「生效此版本」。生效後就鎖住不能改。
規格頁:上面尺寸項次,中間外觀矩陣(紅=拒收、綠=允許及上限)。
規格要改怎麼辦? 回料號頁按「以現行版本開新版」→ 系統複製一份新草稿 → 改 → 生效。舊的批仍然用舊版判定,報告永遠對得上。
提示:外觀矩陣不用一次填完 84 格。先認真定「III 夾砂、IV 氣孔、R 鏽蝕」在各區域的上限,其他留拒收。沒定義到的情況系統會標「待複判」由人判,之後再開新版補進去。

3開檢驗批(每批一次)

誰做:檢驗員
  1. 點 檢驗批 → 右上「開新檢驗批」。
  2. 選料號、檢驗類別(出貨前全檢選 FQC)、數量。
  3. 填鼎新工單號、採購批號、毛胚供應商、爐號、檢驗員(之後報告和退貨都靠這些)。
  4. 按「建立批並開始檢驗」。
擺件:零件依序排好,#1 ~ #N 對應實體順序,量到一半才不會亂。有刻字的可以在件面板填序號。

4量尺寸

誰做:檢驗員
每一列是一件,每一欄是一個尺寸項次。綠=合格、黃=警戒、紅=超差。
  1. 拿起一支量具(例如分厘卡),點該項次第一格(#1)。
  2. 量 #1 → 藍牙量具按傳送鍵(或手打數字)→ Enter → 游標自動跳到 #2。
  3. 一路量到最後一件 → 游標自動跳到下一個項次的第一格 → 換量具。
  4. 三次元量的項目不在這裡打,三次元報告先歸檔;想手填就勾右上「顯示抽檢 / 首件項次」。

逐項 vs 逐件(右上切換)

逐項(預設)同一支量具量完全部件再換下一項。換量具次數最少,最快。
逐件一件量完所有項次再換下一件。零件很大、搬動麻煩時用。
藍牙量具(三豐):接收器 U-WAVE-R 插電腦 USB,用 U-WAVEPAK 設成 Keyboard 模式、資料後加 Enter(設一次)。之後量具按 DATA 鍵 = 自動打字 + Enter,系統不用任何設定。游標在哪格,值就進哪格。
打錯:回到那格改掉再按 Enter 就覆蓋。想清空就刪掉內容按 Enter。↑↓ 可以在同一欄上下移動。

5記外觀(有缺陷才記)

誰做:檢驗員,目視 / 放大鏡看六個區域
  1. 點件號(例如 #3)→ 右邊滑出「件面板」。
  2. 點 區域(密封面 / 端面 A / 端面 B / 外圓 / 內孔 / 非加工面)。
  3. 點 缺陷類型(常見的:III 夾砂、IV 氣孔、R 鏽蝕)。
  4. 填尺寸 mm、數量、時鐘方位(1~12 點鐘,選填)。
  5. 按「拍照」用平板 / 手機相機拍下來(選填)。
  6. 看紅色 / 綠色的「引擎預判」→ 按「加入發現」。
件面板:上半是這件的尺寸,下半記外觀。「引擎預判」會先告訴你這筆依規格是允收還是拒收。
沒有缺陷的件不用做任何事,尺寸量完就自動判允收。責任歸屬預設:鑄造缺陷(I~XII)= 上游,鏽蝕 / 加工損傷 = 廠內,可以改。

6判定與結批

誰做:檢驗員 → 品管主管
  1. 待複判的件一定要由人判:開件面板 → 最下面「人工覆判」→ 填理由 → 判允收或判拒收。
  2. 拒收的件選處置:報廢 / 重工 / 退回供應商 / 特採(件面板右上)。
  3. 所有件都是允收或拒收後 → 批頁最下面「結批」→ 選批結論(允收 / 拒收 / 特採)→ 結批並鎖定。
批頁下方:左邊批資料(鼎新工單等)、右邊結批。
結批後欄位灰掉不能改? 這是正常的(鎖定)。要補資料按「重開此批」。

7出報告

  1. 批頁右上「檢驗報告」。
  2. 右上「列印 / 存 PDF」→ 印表機選「另存為 PDF」→ 就是給客戶的出貨檢驗報告。
A4 報告:基本資料、結果摘要、尺寸統計(含 Cpk)、外觀分類(MSS SP-55)、拒收件明細、簽核欄、逐件附錄。

8退供應商報表(每月)

誰做:品管主管
  1. 點 退供應商報表 → 用 ‹ › 選月份。
  2. 系統列出當月「拒收 + 責任在上游」的所有缺陷,依供應商分,附照片、採購批、爐號。
  3. 列印 → 跟上游談退貨 / 扣款的證據。

AI 外觀檢測(第 1 期,選用)

AI 負責「看」,規則負責「判」,人負責「確認例外」。AI 抓到異常的件會自動變成「待複判」,附熱圖,人點開確認。

AI 帶進來的發現:縮圖是熱圖(紅色 = 不像正常的地方),類型先標「AI 偵測異常(待分類)」,由人改成真正的缺陷類型。
  1. 開批後,零件放治具,用固定位置的手機 / 相機拍每一件,檔名 01.jpg、02.jpg… = 件號。
  2. 在電腦跑 infer.py(資料夾)→ push_to_qc.py(送進該批)。詳細在 aoi/README.md。
  3. 回到批頁,AI 判 NG 的件已標「待複判」→ 點開看熱圖 → 選真正的缺陷類型 → 判定。
AI 只用「OK 件」照片訓練,每個料號每一面各一個模型。要先照 aoi/README.md 的拍照規範拍 100~200 張 OK 件。

常見問題

狀況怎麼辦
開批時說「尚無生效的允收標準」料號的規格還是草稿,回料號頁按「生效此版本」
料號下拉是空的同上,或還沒建料號
量測格灰掉打不進去批已結批,按「重開此批」
結批按了沒反應,說還有幾件未完成有件的「每件」尺寸沒量完,或有待複判件沒人判。看件號旁的標籤
待複判太多外觀矩陣很多組合沒定義。開新版規格把常見組合定清楚
報告抬頭是「請至設定填入公司名稱」設定頁填公司名稱
怎麼備份複製整個 qc-app/data/ 資料夾(裡面是資料庫 + 照片)
平板也能用嗎可以,同一個 Wi-Fi,瀏覽器開 http://電腦IP:3000;拍照按鈕會直接開相機
要重新啟動系統在 qc-app 資料夾執行 pnpm start
