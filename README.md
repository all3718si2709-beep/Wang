# 閥門零件 AI 檢驗與製程優化專案

代工廠圓形閥門零件(3"~14")的品質檢驗數位化、外觀 AI 檢測、與製程數據分析規劃。

> 狀態:**第 0 期工具已可用、第 1 期 AI 檢測 pipeline 已驗證並接通**(2026-09-11)。下一閘門 = 自家零件照片。剩餘待確認事項見 [05-待確認事項](docs/05-open-questions.md)。

## 一句話

**先數位化,再分析,最後才是視覺 AI。** 第一個要做出來的工具是「規格引擎 + 檢驗紀錄」這一層(純軟體、零技術風險、幾週可用),它是後面所有 AI 應用的地基。
